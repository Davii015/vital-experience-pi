01 — Contexto
Qual problema
estamos resolvendo?
📋
Monitoramento subjetivo
Profissionais dependem de relatos verbais do paciente durante sessões de reabilitação e treino, sem dados fisiológicos objetivos.
📈
Falta de histórico integrado
Dados de FC, SpO₂, fadiga e esforço ficam dispersos em planilhas ou anotações, dificultando análise de evolução longitudinal.
⚠️
Risco de intercorrências
Sem alertas em tempo real, episódios de fadiga excessiva, taquicardia ou baixa oximetria podem passar despercebidos durante o atendimento.
🔗
Sistemas inacessíveis
As soluções existentes são caras, proprietárias ou não integram múltiplos tipos de sensor num único painel de controle.

03 — Solução
O que é o
Vital Experience?

Um sistema web completo que conecta sensores vestíveis a uma plataforma de gestão clínica, permitindo monitorar em tempo real o estado físico de pacientes e atletas durante sessões de reabilitação, fisioterapia e treinamento esportivo.

Coleta de dados fisiológicos via sensores (FC, SpO₂, EMG, movimento)
Gestão de profissionais, pacientes e sessões de monitoramento
Relatórios individualizados com evolução histórica
Alertas automáticos por anomalias (fadiga, taquicardia)
Frontend autônomo via localStorage para demonstração offline

08 — Segurança
Segurança e Privacidade
🔑 Autenticação JWT
Tokens com expiração de 7 dias. Verificados em toda requisição ao backend pelo middleware de autenticação. Inválidos são rejeitados com 401.
🔐 bcrypt nas senhas
Senhas nunca armazenadas em texto puro. Hash com bcryptjs (salt rounds = 10). Mesmo que o banco seja comprometido, as senhas permanecem protegidas.
🌍 Variáveis de ambiente
DATABASE_URL, JWT_SECRET e credenciais ficam no .env local, listado no .gitignore. O repositório contém apenas .env.example com placeholders.
📋 LGPD
Dados biométricos e pessoais de pacientes exigem consentimento explícito. O sistema foi projetado com minimização de dados e princípio de necessidade conforme a Lei Geral de Proteção de Dados.
✅ O arquivo .env real nunca foi enviado ao GitHub — apenas .env.example com placeholders está no repositório público.
